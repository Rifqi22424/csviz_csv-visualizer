# 📊 CSViz - CSV Visualizer App

🚀 **CSViz** is a powerful and interactive **CSV Visualizer** built with **Flutter**. Upload any CSV file and instantly generate stunning charts like **Line**, **Bar**, **Scatter**, **Pie**, and even **Radar** – all in real-time.

## 🌟 Features

- 📁 Upload CSV file directly in the app
- 📊 Render charts instantly using [fl_chart](https://pub.dev/packages/fl_chart)
- 🔄 Switch between chart types dynamically
- 💾 Download chart as image:
  - Web: via **Blob**
  - Windows: via **getDownloadsDirectory**
  - Android: via **ImageGallerySaver**
- ⚙️ Built with **BLoC** + **Equatable** for clean state management
- 🌐 Available for **Web**, **Windows**, and **Android**
